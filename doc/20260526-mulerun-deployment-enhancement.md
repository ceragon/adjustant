# MuleRun 原型迭代：战前部署多样化与交互升级

## 概述

为 MuleRun 单文件原型增加**随机出生点**、**阵型部署**、**框选操作**与**战术集火指令**，彻底改变单局游戏的战略维度。本系统是原型 Phase 5 核心内容，建立在 Phase 1-4（基础交互、战争迷雾）之上。

**设计目标：**
- 打破固定出生点导致的“背板”体验，每局开局都有新的战略思考
- 增加战前阵型搭配的深度，让兵种选择不仅是“选几个”，而是“怎么摆”
- 引入 RTS 标准的框选与多单位指令操作，提升操控感和自由度

**适用范围：** 仅 MuleRun `index.html` Canvas 2D 单文件原型。

---

## 一、出生点与地图系统

### 1.1 随机出生点
- **6 个预设出生点位**：左上、左中、左下、右上、右中、右下。
- **每局开局随机分配**：玩家 HQ + 2 座防御塔 + 初始单位 作为一个整体随机出现在其中一个点。
- **敌方同样随机**：AI 也随机出现在 6 个点之一，但**强制与玩家分处地图两侧**（如玩家在左侧 3 点，敌方必在右侧 3 点）。
- **朝向规则**：无论出生在哪个点，阵型的“前”永远朝向地图中心（战场核心区域）。
- **基地布局**：防御塔永远在 HQ 的上下两侧（Y-1 和 Y+1），形成“口袋阵”面向中心。

### 1.2 地图扩大与视口
- **地图尺寸**：**21x21 网格**（比原有 17x17 扩大），预留配置接口方便后续调整。
- **视口缩放（Zoom Out）**：相机默认拉远，使单位视觉上“缩小”，屏幕内可显示约 15x15 格子的区域。
- **相机平移控制**：
  | 操作方式 | 效果 |
  |----------|------|
  | 鼠标移至屏幕边缘 | 相机自动向该方向滚动 |
  | WSAD 键盘 | 手动平移相机 |
  | 点击小地图 | 相机瞬间跳转到小地图点击位置 |
- **小地图**：固定在屏幕右下角，显示全局战场概况，**迷雾区域在小地图上同步为黑色**。

## 二、阵型部署系统

### 2.1 布阵界面改版
- 布阵阶段在选完兵种后，增加**“阵型分配”区域**。
- 界面显示三行：**前排（前）、中排（中）、后排（后）**。
- 玩家通过拖拽兵种图标到对应行，或点击兵种选择归属排，来分配 8 个单位的位置。
- **允许空排**：玩家可以把 8 个单位全放在一排（例如全员射手 Rush），但界面应有提示（如“前排为空，无肉盾保护”）。
- **每排单位类型**：同一排可以混编不同兵种，不限定“前排必须是步兵”。

### 2.2 阵型展开规则
- 开局时，所有单位在 HQ 附近按“前中后”阵型展开：
  - **前排**：在距离 HQ 较远、靠近中线方向的位置集结。
  - **中排**：在 HQ 旁边集结。
  - **后排**：在 HQ 后方（远离中线方向）集结。
- **阵型方向**：根据出生点自动旋转，确保“前”永远朝向地图中心。
- **地形可见性**：战前布阵阶段，**全图障碍物/地形始终可见**（玩家可以看到哪里有路、哪里有墙），但**敌方单位/建筑被迷雾遮盖**。

## 三、框选与操作分离（RTS 标准交互）

### 3.1 输入映射
| 操作 | 输入方式 | 效果 |
|------|---------|------|
| 选择单个单位 | 左键单击 | 选中/取消选中该单位 |
| 框选单位 | 左键拖拽（画矩形框） | 选中框内单位 |
| 移动/攻击指令 | **右键点击** | 被选中的单位向目标移动/攻击 |
| 平移相机 | 鼠标边缘滚动 / WSAD | 查看地图其他区域 |
| 快速跳转 | 点击小地图 | 相机跳转到小地图位置 |

### 3.2 右键菜单处理
- **禁用游戏区域内的右键默认菜单**（`contextmenu` 事件阻止）。
- 进入游戏后在屏幕角落显示提示：“🖱️ 右键 = 移动/攻击 | 左键 = 选择/框选”。

### 3.3 框选规则
- **框选视觉**：左键拖拽时画出半透明矩形选择框（边缘高亮，类似星际/魔兽风格）。
- **宽松模式**：只要单位图标与选择框有重叠即算选中。
- **只选中己方单位**：忽略敌方单位/建筑。敌方必须单独点击选中。
- **选中光晕**：己方单位显示黄色光晕（与 Phase 2 一致）。

### 3.4 指令执行逻辑
- **选中单/多个单位后右键点击空地** → 所有被选中的单位向该位置移动。
- **未选中任何单位时右键点击空地** → 不执行任何操作（或播放提示音“未选择单位”）。
- **右键点击敌方单位/建筑** → 被选中的单位集火该目标。
- **移动过程中遭遇敌人** → 不自动攻击，继续执行移动指令到达目的地后才自动索敌。

## 四、战术指令：优先集火

### 4.1 功能位置
- 侧边战术面板（Tactical Panel）上的常驻按钮组。
- 两个开关按钮：**“优先集火后排”** / **“优先集火前排”**。

### 4.2 交互规则
- **Toggle 开关形式**：点击高亮生效，再次点击取消。
- **互斥逻辑**：同一时间只能开启一个优先级（开启 A 自动关闭 B）。
- **默认状态**：无优先级（攻击最近目标）。

### 4.3 行为逻辑
- **“前后排”定义**：敌方在布阵时已为每个单位分配了前/中/后排**固定标签**，该标签**永久不变**。
  - 即使敌方射手冲到最前线，它依然是“后排单位”。
- **“优先集火后排”生效时**：
  - 所有己方单位优先攻击敌方后排单位（忽略距离）。
  - 后排全灭后自动降级到“中排”。
  - 中排也全灭后自动降级到“前排”。
- **“优先集火前排”生效时**：
  - 逻辑相反，从前往后打。
- **优先级覆盖**：战术面板指令为全局默认优先级，玩家手动右键点击特定目标时，该次指令**覆盖**全局优先级。

## 五、默认行为调整

### 5.1 原地待命
- **单位默认原地待命**，不自动向前推进。
- 不自动攻击范围内的敌人（除非到达移动目的地后自动索敌）。
- 完全由玩家手动下达移动/攻击指令驱动战局。

### 5.2 移动-攻击优先级（继承 Phase 1-3 规则）
- 单位接到移动指令后，**优先完成寻路到达目的地**。
- 移动过程中，即使路过敌方单位攻击范围，也**不会自动停下来攻击**。
- 到达目的地后，**自动搜索攻击范围内的敌方单位并攻击**。
- 攻击过程中目标离开视野 → 立即停止攻击（丢失目标）。
- 目标重新进入视野 → 不自动恢复攻击（需要玩家重新下达指令）。

- 依赖 Phase 1-3 已完成的交互优化（选中光晕、掉血飘字、全军推进/单兵撤退）
