## 🎯 核心体验目标

当前原型的核心玩法已经跑通，本次迭代重点解决**“操作手感”**和**“战术深度”**两个维度的体验断层：
1.  **操作手感**：让玩家清楚“我点了什么”以及“指令是否生效”。
2.  **战术深度**：打破“无脑推进”和“缩塔防流”，引入障碍与微操空间。

---

##  交互逻辑共识（策划标准）

以下逻辑为**最终体验标准**，请 MuleRun 按此效果实现：

| 交互场景 | 策划要求（体验层） | 逻辑规则 |
| :--- | :--- | :--- |
| **受伤反馈** | **数字从头顶飘出** | 伤害数字不应遮挡单位主体，应从单位上方浮现并向上飘散。 |
| **选中反馈** | **颜色区分敌我** | 选中己方单位显示**黄色**光效；选中敌方单位显示**红色**光效；选中敌方塔显示**橙色**光效。 |
| **点击敌人** | **自动集火** | 点击敌方任意目标（单位/塔/HQ），全军自动攻击该目标。 |
| **攻击队形** | **拒绝重叠** | 多个单位攻击同一目标时，应自动寻找不同站位，呈**包围/散开**态势，避免重叠在同一像素点。 |
| **移动光标** | **指尖指示** | 点击空地移动时，在目标点显示一个**小手图标**，单位开始移动后光标消失。 |
| **点击空地** | **全军推进** | 点击空地，所有处于非撤退状态的己方单位向目标点移动。 |
| **点击友军** | **单兵撤退** | 点击己方单位，**仅该单位**执行撤退，不影响其他单位。 |
| **撤退归队** | **满血自动归队** | 撤退单位回满血后，自动重新加入战斗队列。 |
| **障碍物** | **阻挡视线与路径** | 障碍物不仅阻挡单位移动，也应**阻挡防御塔的攻击视线**。 |

## 🛠️ 迭代任务清单（按效果导向）

### 任务 1：优化伤害提示位置
- **现状问题**：受伤数字出现在单位中间，遮挡图标。
- **修改要求**：调整伤害数字的生成位置，使其始终位于单位正上方，并带有向上飘升的动画效果。

### 任务 2：增加选中框（光晕）
- **需求**：为点击选中的单位/建筑增加视觉高亮。
- **效果**：
  - 己方单位：黄色光圈。
  - 敌方单位：红色光圈。
  - 敌方塔：橙色光圈。
  - 敌方 HQ：红色加粗光圈。
- **目的**：解决玩家“凭感觉操作”的痛点，明确选中状态。

### 任务 3：优化全军推进逻辑
- **现状问题**：点击远处空地，部分单位无反应或不受控制。
- **修改要求**：
  - 点击空地时，确保场上所有非撤退状态的单位都能响应移动指令。
  - 遇到障碍物时，单位应能自动寻路绕行，支持多单位分流，不排长队。

### 任务 4：优化集火与攻击逻辑
- **现状问题**：单位攻击时容易挤成一团，且无法手动指定集火目标。
- **修改要求**：
  - 实现“点击敌人=全军集火”的功能。
  - 优化攻击时的站位逻辑，单位在射程范围内应自动分散站位，不要重叠。
  - **指令优先级**：集火指令优先于撤退指令（残血单位也应响应集火冲锋）。

### 任务 5：引入地图障碍物
- **需求**：在地图中增加静态障碍物（如岩石/墙壁）。
- **布局建议**：在地图中轴线两侧放置障碍块，留出侧翼通道（参考 ASCII 布局图）。
- **规则要求**：
  1.  **阻挡移动**：单位不可穿过障碍。
  2.  **阻挡视线**：防御塔不能攻击障碍物背后的目标。
- **目的**：逼迫玩家进行战术走位，打破“缩塔防流”。

### 任务 6：添加移动光标（小手）
- **需求**：点击空地发出移动指令后，在目标位置生成一个“小手”图标。
- **逻辑**：当单位开始向该目标移动时，小手图标自动消失。
